# <span style="color:#004C97">Workshop on Big Data for Macroeconomic Statistics</span>
## <span style="color:#707372">*Singapore Regional Training Institute (STI) Edition, 2026*</span>

📖 **Read the materials online:** <https://imforg-public.github.io/imf_big_data_workshop_sti26>

## <span style="color:#004C97">**Background**</span>
This repo houses the materials for **Big Data for Macroeconomic Statistics** (November 2–6, 2026), organized by the **IMF Big Data Center (BDC)** at the *Singapore Regional Training Institute (STI)* in Singapore.

These workshops are aimed at officials from national statistical offices, central banks, and other government institutions, in order to strengthen their capacity to use Big Data sources and advanced technologies to improve the timeliness and granularity of macroeconomic statistics for surveillance and research purposes.

The workshop, conducted by BDC data scientists, combines lectures, hands-on technical sessions, and peer discussions.

## <span style="color:#004C97">**Workshop content and flow**</span>
The workshop's focus is on practical applications of Big Data sources and technologies to improve macroeconomic monitoring.
The topics on this site are organized in line with the workshop schedule:

- **Getting Started:** Set up notebooks to ensure access to Google Colab and Google Earth Engine
- **Satellite Data Fundamentals:** Explore use of satellite imagery to estimate economic activity and generate high frequency indicators
- **GDP Nowcasting:** End-to-end workflow for GDP nowcasting, including data extraction, preparation, machine learning model selection, performance analysis, and interpretation
- **Automatic Identification System (AIS) and PortWatch:** Analysis of international trade disruptions using AIS data and the IMF's [PortWatch](https://portwatch.imf.org) platform
- **Text Analytics:** Use of natural language processing to extract signals from unstructured text, covering NLP fundamentals, sentiment analysis, and text classification
- **Capstone Project:** A group assignment applying the material learned throughout the week to a practical problem, using Python notebooks, cloud based infrastructure, geospatial tools, and open data sources

## <span style="color:#004C97">**Working with the notebooks**</span>
All sessions run in **Google Colab**.

Open a notebook from the navigation menu, use the 🚀 launch button at the top of the page to open it in Colab, then save your own copy (**File → Save a copy in Drive**) so that your edits and results are kept.
